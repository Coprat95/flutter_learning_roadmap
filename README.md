Flutter Learning Roadmap
Este repositorio contiene mis ejercicios, prácticas y mini‑proyectos realizados durante mi proceso de aprendizaje de Flutter.
Mi objetivo es adquirir un nivel sólido para afrontar una prueba técnica y desarrollar aplicaciones móviles multiplataforma con buenas prácticas.

🚀 Objetivos del repositorio
Dominar los fundamentos de Dart

Aprender los widgets básicos y la estructura de Flutter

Practicar Stateful / Stateless, navegación y manejo de estado

Consumir APIs reales con FutureBuilder

Crear pequeñas apps funcionales

Preparar una mini‑app final como simulación de prueba técnica

🛠️ Tecnologías
Flutter SDK

Dart

VS Code

Android SDK / Chrome

En progreso — actualizando diariamente mientras avanzo en mi preparación.
